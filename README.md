# Мережевий хаб — навчальний модуль для 10 класу

## Публікація на GitHub Pages
1. Створіть порожній GitHub-репозиторій.
2. Завантажте `index.html` та папку `assets`.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть `Deploy from a branch`.
5. Оберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Дочекайтеся публікації та відкрийте адресу GitHub Pages.

## Можливості
- Теоретичний блок із тематичною ілюстрацією.
- 20 інтерактивних вправ: вибір відповіді, сортування, встановлення відповідностей, упорядкування drag-and-drop.
- Реєстрація учасника (ім'я та клас).
- Лічильник спроб, прогрес і бали.
- Збереження відповідей у LocalStorage браузера.
- Формування звіту для друку або збереження у PDF через системне вікно друку браузера.

## Важливе обмеження
GitHub Pages — статичний хостинг і не має власної бази даних. Результати зберігаються лише у браузері та на пристрої, де учень працює. Для централізованого збору відповідей усіх учнів потрібен бекенд (наприклад, Firebase або Supabase) та окрема конфігурація доступу й захисту даних.

## Технічні примітки
Сайт не потребує збірки або встановлення залежностей. Для drag-and-drop використовується HTML Drag and Drop API. PDF-звіт відкривається як форматована сторінка, яку можна зберегти у PDF через `Друк → Зберегти як PDF`.
